# 🎨 My Personal Portfolio

A modern, full-stack portfolio website built to showcase my projects and skills. Designed with a custom "Dark & Orange" theme, it features smooth CSS animations, an infinite scrolling project slider, and a fully functional backend for handling contact requests.

## 🚀 Features

* **⚡ Modern UI/UX:** Responsive design with a dark mode aesthetic and custom gradients.
* **🔄 Infinite Project Slider:** Auto-scrolling marquee for projects with manual pause/control.
* **📧 Real-Time Notifications:** Contact form integrated with **Nodemailer** to send instant email alerts.
* **💾 Database Integration:** All contact messages are securely saved to **MongoDB**.
* **✨ Advanced CSS:** Custom keyframe animations (glowing rings, smoke effects, hover transitions).

## 🛠️ Tech Stack

**Frontend:**
* React.js
* CSS3 (Variables, Flexbox, Grid, Keyframes)
* React Icons

**Backend:**
* Node.js
* Express.js
* Mongoose (ODM)
* Nodemailer (Email Service)

**Database:**
* MongoDB Atlas (Cloud)
